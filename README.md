# Library Management System (SQL Server, T-SQL)

A relational database system for running a library: members, books and loans, with the business logic written directly in T-SQL.

## Overview

Designed and built a 5-table relational database in Microsoft SQL Server covering the full lending workflow, from member registration to book returns, with overdue tracking built in.

## Tech

- Microsoft SQL Server
- T-SQL (stored procedures, views, complex queries)

## What's inside

- **5-table relational schema** for member management, book tracking and loans
- **4 stored procedures** for the core lending operations
- **8+ complex queries** answering real business questions
- **Views** for current loans and overdue tracking
